Cloud Hub Project Journey

Our course and website development journey began with a structured vision to deliver a comprehensive, comparative learning experience focused on AWS, Azure, and GCP cloud platforms. This document outlines the phases, features, and structure of the project.

1. Ideation & Planning

We began by identifying the need for a clear and comprehensive comparison of the three leading cloud platforms—AWS, Azure, and GCP. The goal was to design a modular course that effectively highlights the unique strengths, differences, and common use cases of each platform. Additionally, we aimed to equip learners with the necessary knowledge to successfully pursue the Fundamentals Certifications for these platforms, incorporating targeted quizzes to reinforce learning and ensure readiness. To ensure structured development and continuous improvement, we followed the Agile methodology, organizing the project into a Product Backlog consisting of three sprints. Each sprint focused on reviewing 10 course modules, encompassing data validation, design alignment, and content development. This sprint-based approach allowed for focused iterations, timely feedback, and incremental delivery of a high-quality learning experience.

2. Research & Content Gathering

We leveraged AI tools, particularly ChatGPT, to enhance content drafting, streamline structure, and maintain accuracy. Information was curated from credible sources, including official documentation, industry best practices, and user insights. All AI-generated content was reviewed and refined by our team to ensure clarity, relevance, and engagement. The course framework was built around 70+ cloud services grouped into 30 categories across AWS, Azure, and GCP. A consistent 11-point evaluation model enabled comparative analysis. Contextual hyperlinks to definitions, use cases, and success stories enriched the learning experience. Agile reviews ensured technical integrity and learner-centered design throughout.

3. Course & Website Development

The course is hosted on a responsive website developed using HTML5, CSS3, and JavaScript. It begins with a professional landing page that includes team credits and a "Start Course" button linking to a high-level overview with visual context. The Table of Contents lists 30 modules, each expandable to submodules. JavaScript powers the navigation across pages. Each module provides topic descriptions, while submodules offer a comparative analysis across AWS, Azure, and GCP. Each page includes a Home button for easy navigation. The visual design follows DXC Industry standards to ensure an enterprise-grade aesthetic. Quizzes are integrated after every 10 modules and a final comprehensive quiz is provided, all developed using Microsoft Power Apps.

4. Integration & Deployment

All modules and interactive elements were integrated into a cohesive web application with smooth transitions and consistent user experience. Version control and collaboration were managed via GitHub, facilitating feature merging and code tracking. Deployment was executed through Netlify, connected to the GitHub repository for continuous deployment. Every push to the main branch triggered automatic builds and updates, ensuring streamlined development and scalability.

5. Feedback & Optimization

We focused on optimizing both performance and user experience by refining the codebase, minimizing load times, and ensuring a responsive design across various devices and screen sizes. We applied best practices in front-end optimization, such as compressing images, reducing unnecessary JavaScript, and leveraging browser caching. To ensure smooth navigation and intuitive interaction, we conducted testing sessions and gathered feedback from Cloud Hub team members as well as potential users. This feedback helped us identify usability issues and performance bottlenecks. Based on these insights, we made iterative enhancements to improve layout structure, link accessibility, and overall responsiveness. We also plan to implement performance monitoring and analytics tools to continuously track user behavior and make data-driven decisions for future updates.
